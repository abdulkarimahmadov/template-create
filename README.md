# Music Portal Template

This is a music news portal template based on a WordPress theme.

## Structure

```
.
├── assets/
│   └── css/           # Local CSS files
│       ├── bootstrap.css
│       ├── responsive.css
│       ├── camera.css
│       ├── style.css
│       ├── flexslider.css
│       ├── owl.carousel.css
│       ├── owl.theme.css
│       ├── cherry-plugin.css
│       ├── contact-form-7-styles.css
│       ├── magnific-popup.css
│       └── main-style.css
└── *.html              # HTML template files
```

## Features

- Responsive Bootstrap-based layout
- Music news and articles sections
- Image sliders and carousels
- Contact forms
- Gallery support
- Widget areas for sidebars

## Usage

1. Open any of the HTML files in a web browser
2. All CSS styling is now loaded from local files in the `assets/css/` directory

## CSS Files

All CSS files have been localized to ensure the template works without external dependencies:

- **bootstrap.css** - Core Bootstrap framework styles
- **responsive.css** - Responsive design styles
- **camera.css** - Camera slider styles
- **style.css** - Main theme styles
- **flexslider.css** - FlexSlider plugin styles
- **owl.carousel.css** - Owl Carousel plugin styles
- **owl.theme.css** - Owl Carousel theme
- **cherry-plugin.css** - Cherry plugin styles
- **contact-form-7-styles.css** - Contact Form 7 styles
- **magnific-popup.css** - Magnific Popup lightbox styles
- **main-style.css** - Additional theme styles and customizations

## Browser Support

- Modern browsers (Chrome, Firefox, Safari, Edge)
- IE9+ (with some limitations)

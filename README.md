# Music News - Website Template

A fully functional HTML/CSS/JS music news portal website template.

## Features

- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **Multiple Pages**: Home, About, Blog, Gallery, and Contact pages
- **Clean Code**: Well-structured HTML5, CSS3, and vanilla JavaScript
- **Modern Styling**: Beautiful design with smooth transitions and hover effects
- **Navigation Menu**: Dropdown menu support with mobile-friendly navigation
- **Contact Form**: Working contact form structure
- **Gallery**: Photo gallery page for showcasing images
- **Blog Section**: Blog listing with sidebar
- **Social Media Links**: Footer social media integration
- **Back to Top Button**: Smooth scroll to top functionality

## How to Use

1. **Open the Website**: Simply open `index.html` in your web browser
2. **Navigate**: Use the navigation menu to explore different pages
3. **Customize**: Edit the HTML files to change content
4. **Style Changes**: Modify `css/style.css` to customize colors and styles
5. **Add Images**: Replace placeholder images in the `images/` folder with your own

## Customization Guide

### Changing Colors

Edit `css/style.css` and modify these key colors:
- Primary color (red): `#e74c3c`
- Dark background: `#262626`
- Header background: `#1a1a1a`

### Adding Your Logo

Replace `images/logo.svg` with your own logo image (PNG, JPG, or SVG format).

### Adding Content

1. Open the HTML file you want to edit
2. Find the section you want to modify
3. Update the text, images, or links
4. Save and refresh your browser

### Adding More Pages

1. Copy an existing HTML file (e.g., `about.html`)
2. Rename it to your new page name
3. Update the content
4. Add a link to it in the navigation menu

## Deployment

### Local Development
Simply open `index.html` in your browser.

### Web Hosting
Upload all files to your web host via FTP or hosting control panel:
1. Upload all HTML files to the root directory
2. Upload `css/`, `js/`, and `images/` folders
3. Ensure file structure remains the same

### GitHub Pages
1. Push this repository to GitHub
2. Go to repository Settings
3. Enable GitHub Pages from the main branch
4. Your site will be live at `https://yourusername.github.io/repository-name/`

## Customization Tips

### Change Website Title
Edit the `<title>` tag in each HTML file.

### Update Contact Information
Edit the footer section and contact page with your details.

### Add Social Media Links
Update the social media links in the footer:
```html
<a href="https://facebook.com/yourpage" class="social_link">FB</a>
```

### Modify Navigation Menu
Edit the `<nav>` section in each HTML file to add/remove menu items.
